## EARS Requirement Pattern
**Event driven:** When a ReferralDocument is stored in Blob Storage (ReferralReceived event), the Referral aggregate shall trigger the AITriageClassifier domain service to extract text from the document (using OCR if needed), invoke the AI model to classify specialty, assign urgency, extract key fields (patient name, DOB, symptoms, duration, red flags), generate a clinical summary, create a TriageRecord with the TriageClassification value object, emit ReferralTriaged event, and store the triage record in Cosmos DB.

---

## Requirement Statement
When a ReferralDocument is stored in Blob Storage (triggered by ReferralReceived event), the Referral aggregate shall invoke the TextExtractor domain service to extract text from the document using OCR if needed, invoke the AITriageClassifier domain service to send extracted text to the AI model to classify medical specialty (cardiology, orthopedics, neurology, dermatology, or general medicine), assign urgency level (routine, soon, or urgent), extract key clinical fields (patient name, date of birth, symptoms list, duration, red flags list), and generate a short clinical summary, create a TriageRecord entity with a TriageClassification value object containing all extracted and classified data, emit ReferralTriaged domain event with complete payload including ReferralId, TriageRecordId, specialty, urgency, patient details, symptoms, duration, red flags, clinical summary, and processing latency, and persist the Referral aggregate with the new TriageRecord to Cosmos DB.
